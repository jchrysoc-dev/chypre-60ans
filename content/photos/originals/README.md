# Your own photos

Put the original pictures (.jpg, .png or .webp) in this folder.

They are **not published**. They stay on your computer. The command `npm run photos` makes small, web-sized copies in `public/photos/` (without camera or location details), and only those are published.

To use a photo on the website, copy `../_template.yaml` to a new file in `content/photos/`, name the picture in `source_file`, and run `npm run photos`.
